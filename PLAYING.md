# Play Classless Survivors

Open the hosted game's address in a recent browser. No account, payment or
download is required. Android Chrome, tablet and desktop Chromium are the tested
targets. A full run lasts 12 minutes, plus time spent choosing upgrades or paused.

1. Open **Talents**. You have eight points and can freely mix Warrior, Mage,
   Rogue, Priest, Warlock and Hunter talents. Select a node to inspect its effect
   and prerequisites, then allocate. **Free respec** costs nothing between runs.
2. Select **Enter the clearing**. Attacks aim and fire automatically. Move to
   avoid enemies and collect the green experience shards left by defeated foes.
3. On each level, choose one of three temporary upgrades. Combat pauses while
   you decide. Build on your talents, add a new attack, or take needed protection.
4. Dodge the guardians' warning shapes at **3:00, 6:00 and 9:00**. Defeat all
   three and survive until **12:00** to win. Defeat still earns progress.
5. Return to Talents, research new possibilities, change your build and try again.

For a first hybrid, try **Iron Reprisal → Sweeping Blade → Frostbreak** in Warrior,
**Arcane Echo → Rime Sigil → Shatterglass** in Mage, and **Ember Communion → Searing
Grace** in Priest. Those eight initially available talents turn frost, physical
hits and healing into more attacks. This is a starting suggestion; experiment.
Every character has an automatic ember attack, even with no talent points spent.

## Controls

| Device | Movement | Pause |
| --- | --- | --- |
| Phone/tablet | Press and drag inside the arena; lift to stop | **Pause** below/beside the arena |
| Desktop | **WASD** or **arrow keys** | **Pause** or **Escape** |

The game occupies one fixed window: the page never scrolls. **Menu** opens
sound/display, offline support, enemy help and the current run build inside it.
Long menus scroll internally. Touch menus work by tapping. Upgrade choices and talent details remain scrollable.
The arena fits portrait or landscape. Rotation, leaving the tab and opening help
pause combat; resume explicitly. **Sound & display** offers mute, volume and reduced
motion. Browser zoom remains available outside the active arena gesture.

## Progress and backups

Runs grant limited insight to research the six capstone talents. Completing two
runs grants a ninth talent point; five grants the tenth and final point. Losses
count. Permanent progress expands choices without unlimited stat purchases.
You can select **eight distinct temporary upgrades** per run; improving an
already selected upgrade uses no extra slot. **Second Wind** recovery uses no
slot. Later levels require more XP, up to level 24.
Run upgrades disappear when the run ends. Research survives free respecs.

**Pause → Abandon run** ends a run without rewards or completed-run credit.
You can then change your build and start again.

Your completed progress and current talent allocation save automatically to this
browser and site address. **Talents → Progress, saved builds & backups** offers
three named build slots. Changing a draft does not overwrite a slot until you
select **Save build** again. Closing/reloading discards unfinished combat without
granting a reward; it keeps completed progress and builds.

Before clearing site data or changing device/browser/site, use **Backup and
restore → Export backup**. To restore, choose the JSON file or paste its text,
select **Review backup**, then **Replace local progress**. Imports replace progress.
Sound/display settings are separate. Browser storage can be denied or evicted;
if saving reports a failure, export before leaving. There is no cloud sync.

## Offline play and installation

Open the production game online and wait for **Offline ready** under **Menu → Offline &
installation**. You can then reopen and play offline. Android Chrome's install
button/menu can add it to your home screen; installation is optional. Open an
installed copy online once and confirm readiness there, since some app containers
use separate storage. Keep backups. OS installation has not been tested on hardware.

If offline loading fails, reconnect and choose **Save game offline**. For updates,
choose **Check for updates**, finish your run, close **all** game tabs and installed
windows, then reopen. Updates wait for those windows to close and preserve saves;
they never force a running game to reload.

If the older layout remains, finish your run and open
[/Classless-survivors/update.html](https://fathernotimegames.github.io/Classless-survivors/update.html).
Select **Update game and reopen** while connected. This explicit recovery verifies
the complete replacement before activating it; it preserves saves, settings and
other applications' caches. Only the recovery window reloads. Failed downloads
keep the existing offline game. **Menu → Offline & installation** displays the
loaded game version (currently **1.1.1**). Avoid clearing browser site data, which
also removes character progress.
